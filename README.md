# Torpedos
### Intentionally misspelled

This is my first real game ever made in Godot.
When I say real I mean it isn't something I started then dropped :)
[Also available on itch!](https://vincydoodle.itch.io/torpedos)

This game is inspired by the arcade game Asteroids.

This game supports gamepad
#### Controls:
Forward - W, UP, JOYSTICK UP, D-PAD UP
Backward - S, DOWN, JOYSTICK DOWN, D-PAD DOWN
Left - A, LEFT, JOYSTICK LEFT, D-PAD LEFT
Right - D, RIGHT, JOYSTICK RIGHT, D-PAD RIGHT

In order to move around you rotate side to side and then moving forward pushes you in the direction
of the red arrow on the main character, however if you rotate while moving forward you will continue to move
in the same direction until you fully let go of the Forward keybind.
